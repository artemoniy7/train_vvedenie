# Простой тетрис на Pygame

## Как запустить игру

1. Установите Python версии 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Установите необходимые библиотеки командой:

```bash
python -m pip install -r requirements.txt
```

4. Запустите игру командой:

```bash
python main.py
```

## Linux и сенсорный экран

При запуске в Linux программа автоматически определяет операционную систему и открывает игру на весь экран с размером 1224×2720 пикселей. Под игровым полем появляются большие экранные кнопки, которыми можно управлять касанием или щелчком мыши:

- **ВЛЕВО** — переместить фигуру влево.
- **ПОВОРОТ** — повернуть фигуру по часовой стрелке.
- **ВПРАВО** — переместить фигуру вправо.
- **ВНИЗ** — опустить фигуру на одну клетку.
- **СБРОСИТЬ** — мгновенно опустить фигуру до места приземления.
- После завершения игры нажмите **НАЧАТЬ ЗАНОВО**, чтобы начать новую партию.
- **Esc** — выйти из игры с подключённой клавиатуры.

На Windows и других не-Linux системах остаётся обычное окно и управление клавиатурой.

## Управление на клавиатуре

- **Z** — переместить фигуру влево.
- **X** — переместить фигуру вправо.
- **A** — повернуть фигуру против часовой стрелки.
- **D** — повернуть фигуру по часовой стрелке.
- **S** — мгновенно опустить фигуру до места приземления.
- **R** — начать заново после завершения игры.
- **Esc** — выйти.

За каждую удалённую линию начисляется 100 очков.
