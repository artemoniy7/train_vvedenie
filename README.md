# Railway Simulator

Начальный каркас 2D-симулятора железной дороги на Python и Pygame.

## Запуск

1. Установи Python 3.10 или новее.
2. В терминале в папке проекта выполни:

   ```bash
   python -m pip install -r requirements.txt
   python main.py
   ```

3. Нажми `Esc` или закрой окно, чтобы выйти.

## Структура

- `main.py` — игровой цикл, окно и обработка событий.
- `settings.py` — размеры окна, FPS и основные настройки.
- `requirements.txt` — зависимости проекта.
- `assets/textures/` — спрайты и текстуры.
- `assets/fonts/` — шрифты.
- `assets/sounds/` — звуковые эффекты.
- `utils/` — вспомогательные функции.
- `scenes/` — игровые сцены.
- `entities/` — игровые объекты: поезда, сигналы и станции.
- `data/` — конфигурации и данные уровней.
